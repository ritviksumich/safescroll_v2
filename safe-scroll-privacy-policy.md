# Privacy Policy for Safe Scroll

Last updated: May 16, 2026

Safe Scroll is a Chrome extension that helps parents support safer, healthier browsing for children by using local AI to scan webpage text and images and apply parent-configured highlight or blur effects.

## Data Handled by the Extension

Safe Scroll may read website content, including visible text and images on webpages, in order to provide its content screening feature.

Safe Scroll does not collect personally identifiable information, financial information, health information, authentication information, location data, or payment information.

## How Data Is Used

Website content is processed locally on the user's device using the Gemma 4 E2B ONNX model.

The extension uses webpage content only to classify page elements and decide whether to leave them clear, highlight them, or blur them based on the parent's configured settings and moderation prompt.

## Data Sharing

Safe Scroll does not sell user data.

Safe Scroll does not send webpage content to the developer's servers or to an external moderation API. Website content is processed locally on the user's device.

## Remote Connections

Safe Scroll may connect to Hugging Face or related CDN hosts to download Gemma 4 E2B ONNX model files when the user chooses to load the model.

These downloads are model files used for local inference. They are not webpage content and are not used to send browsing data to Hugging Face or any external moderation service.

## Local Storage

Safe Scroll uses Chrome local storage to save extension settings, such as the parent's moderation prompt, scan preferences, model readiness, and toggle settings.

## Limited Use

Safe Scroll uses handled data only to provide or improve its single purpose: parent-guided, local web content screening for children.

Safe Scroll does not use user data for advertising, profiling, creditworthiness, or lending purposes.
